🎯 游戏概述

游戏类型

增量放置 + 资源整合，类似银河奶牛（Galaxy Cow）。
设备 = 装备，有多级升级树。每次提升解锁新内容。
核心驱动：资源 → 设备 → 更多资源 → 更好设备。

世界观

近未来，太空旅行已实现但昂贵。主角是太空穷游者，旅途中资金耗尽被迫停靠月球。
目标：攒资源 → 修好/买到飞船 → 离开月球。
科学范畴内，不玄幻。无死亡，惩罚 = 效率降低。

核心设计原则

  • 🔹 无 Game Over — 资源耗尽只降效率
  • 🔹 网购兜底 — 所有关键物资可网购（贵）
  • 🔹 多路线 — 同一种资源多种获取途径
  • 🔹 副产物链 — 废物利用，深度技术树
  • 🔹 放置友好 — 离线也有产出（需设备支持）

🔧 气体压缩机 — 3 级升级树

气体压缩机是制氧路线的必经节点——没有它就没有可携带气瓶，玩家无法外出 EVA。

T1 活塞式压缩机

初级 · 月球环境下损耗大

输出压力30 MPa
生成速度慢
耗电中
气体纯度中（可呼吸 / 燃料电池）
气阀组损耗2% / 瓶 → 50次报废

消耗品

🪫 气阀组购买 3D打印 比机器便宜
🛢 润滑油仅购买 1组用3次，每次永久 -0.2%/瓶损耗

T2 离子式压缩机

中级 · 金属阀组，寿命更长

输出压力70 MPa
生成速度中
耗电中高
气体纯度高（高温生产燃料）
金属阀组损耗1% / 瓶 → 100次

消耗品

🔩 金属阀组购买 冶炼自制 需铁矿+铬矿 1500℃
🛢 液压油仅购买 消耗品

T3 电化学压缩机

高级 · 航天级纯度

输出压力150 MPa
生成速度快
耗电中高
气体纯度极高（航天推进剂 / 最高温燃料）
MEA 寿命长寿命

消耗品

🔬 膜电极 MEA仅购买 不可生产
💎 铂金催化剂仅购买 贵！

🫙 储气瓶 — 4 级升级树

储气瓶决定可携带气体量和外出活动半径。材料来源与冶炼技术挂钩。

T1 钢气罐

材料钢（月壤炼铁）
重量大
储气量中
制作可自制 可购买

T2 钢胆碳纤瓶

材料钢 + 碳纤维
重量中
储气量中
制作可自制 可购买

T3 铝胆碳纤瓶

材料铝 + 碳纤维
重量轻
储气量高
制作可自制 可购买

T4 全碳瓶

材料纯碳
重量最轻
储气量最高
制作可自制 碳稀有！
碳元素获取途径（卡科技树的关键稀有资源）：
① 每个陨石坑含一个碳矿，刷新时间控制总量
② 提炼月壤微量副产碳（慢）
③ 后期人工光合作用产碳（科技解锁）
铝元素：月壤含铝，但提炼耗能极大——用能源卡住 T3 进度。
铁/钢：月壤炼铁相对容易，T1/T2 可较快达到。

🔋 电池系统 — 5 级升级树

电池决定夜间续航能力。储电量和放电效率是两个独立维度——储电多但放得慢也会卡脖子。

T1 镍氢电池 Ni-MH

初始电池 · 皮实耐用

原料镍 + 氢 可自制
储电量少
放电效率低
特点买得起、造得出、但放电慢会卡住

T2 铝离子电池 Al-ion

储电中 · 放电中

原料铝 + 钛 可自制
储电量中
放电效率中
瓶颈铝冶炼耗电大

T3 钠离子电池 Na-ion

储电中 · 放电中上

原料长石（月表常见）可自制
储电量中
放电效率中上
优势原料易得，月球长石丰富

T4 燃料电池 PFC

储电中 · 放电高

原料氢气 + 氧气 可自制
储电量中
放电效率高
本质即燃烧发电模块的"电池形态"

T5 再生燃料电池 RFC

储电高 · 放电高 · 终局装备

原料氢气 + 氧气 可自制
储电量高
放电效率高
瓶颈再生部件仅末期可造
设计意图：电池升级树的"卡点"各不相同——
Ni-MH → Al-ion：卡铝冶炼能耗
Al-ion → Na-ion：卡长石提纯技术
Na-ion → PFC：卡气体压缩+储存产业链成熟度
PFC → RFC：卡再生部件材料（末期内容）
每级电池 都可购买，但自制更划算。初期金属类电池无法大规模制造，靠购买过渡。

📡 信号基站 — 4 级升级树

信号基站是联系地球的命脉。没有信号 = 无法网购 = 无法购买关键消耗品。
信号越好 → 订单越快到达、价格越优惠、解锁远程操作能力。

T0 无基站 · 初始状态

通讯方式飞行仓自带应急天线（功率极低）
网购❌ 不可用
订单❌ 不可用
远程采矿❌ 不可用
现状只能靠自给自足，网购兜底不可用

T1 折叠天线阵

展开式抛物面天线 · 初期可负担

覆盖范围近月面（~100km 半径）
网购解锁✅ 基础商城可用
订单速度慢（2~3 个昼夜到达）
价格系数×1.5（偏远地区附加费）
耗电低（~50W）
特殊功能—
原料铝 + 铜线 可自制 可购买

T2 相控阵基站

电子扫描阵列 · 无需机械转动

覆盖范围中等距离（~500km）
网购解锁✅ 中级商城解锁
订单速度中（1~2 昼夜到达）
价格系数×1.2
耗电中（~200W）
特殊功能📡 可扫描附近陨石坑资源分布
原料硅晶片 + 稀土磁体 部分自制

T3 深空通讯阵列

大型碟形天线 · 直接联系地球

覆盖范围全月面 + 近月轨道
网购解锁✅ 高级商城解锁（含稀有物品）
订单速度快（0.5~1 昼夜到达）
价格系数×1.0（标准价）
耗电高（~1kW）
特殊功能🤖 远程采矿控制 · 📊 资源储量探测
原料高精度伺服 + 碳纤维结构 稀有材料

T4 量子中继站

终局通讯 · 量子纠缠超距传输

覆盖范围全太阳系
网购解锁✅ 终极商城（所有物品）
订单速度即时到达
价格系数×0.8（VIP 折扣）
耗电极高（~5kW）
特殊功能🛸 叫飞船（终局）· 🌍 地球市场实时行情
原料量子晶体 + 超导线圈 仅可购买
信号基站的游戏意义：
• T0→T1 是第一个重大解锁——开通网购，获得兜底保障
• T1→T2 解锁资源扫描，玩家不再盲目找矿
• T2→T3 解锁远程采矿（放置玩法核心：离线后矿机继续工作）
• T3→T4 是终局钥匙——叫飞船离开月球的条件之一
• 信号站必须持续供电，断电 = 失去信号 = 失去网购和远程控制

🏠 基地房间系统

基地是多个"页面"组成的合集，每个页面 = 一个功能房间。类似银河奶牛的"牧场页面"概念。

  • 冶炼炉（铁/铝/铬）

🌡 常温作业室

  • 电解器-冰（月冰→H₂+O₂）

  • 尿液净化系统

  • 3D 打印机（零件自制）

📊 关键数值平衡参考

时间系统

1 月球昼夜≈ 游戏 240s（现实 4min）
白天 / 夜晚各约 120s
14 游戏天≈ 现实 1 天（约 1h）
1 游戏天≈ 4.3 分钟现实时间

能源平衡（设计目标）

白天太阳能日常消耗 × 1.5~3（视光伏板数量）
盈余分配电池充满 → 剩余→加热月壤制气瓶
夜晚消耗日常 × 1.3（保温）+ 设备待机
夜间来源电池放电 + 燃烧发电
初期馈赠够 2 次夜晚的能量储备

氧气系统

基础消耗1.5% / min（被动词条）
O₂ > 20%正常 · HUD 蓝色
O₂ 10~20%低氧警告 · HUD 黄色
O₂ < 10%严重不足 · HUD 红色
O₂ = 0%速度 ×50% · 禁止采矿 · 植物枯萎
应急恢复紧急电解兜底 +0.15/min（很慢）

资源采集

月壤月表普遍分布，采集容易
月冰极地区域丰富，赤道稀少
碳矿每个陨石坑 1 个，定时刷新
铁月壤提炼，相对容易
铝月壤提炼，耗电极大
铬矿稀有矿产，特定区域
长石月表普遍，钠离子电池原料
