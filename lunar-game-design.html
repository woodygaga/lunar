一、游戏总览

定位

增量放置+资源整合，设备即装备、多级升级树、每级解锁新内容。
近未来太空穷游者，旅途中资金耗尽被迫停靠月球。
目标：攒资源 → 修好飞船 → 离开月球。

无死亡机制，惩罚 = 效率降低。科学范畴，不走玄幻。

二、资源采集系统

🌑 月壤

分布月表普遍
采集月球车 EVA，10~50g/次
用途加热→水+废料 / 熔融电解→O₂ / 固态电解
副产微量碳、铁、铝
难度低 · 基础资源

🧊 月冰

分布极地区域丰富，赤道稀少
采集极地 EVA（带回费电）
用途水解→O₂+H₂（中耗电路线）
难度中 · 需长途运输

💎 碳元素 · 关键稀有

途径①陨石坑碳矿 · 每坑1个 · 定时刷新
途径②月壤提炼微量碳（慢）
途径③后期人工光合作用产碳
卡点全碳瓶/碳纤维的瓶颈，控制终局进度

⛏ 其他矿产

铁月壤提炼 · 相对容易 → 钢气罐/结构件
铝月壤提炼 · 耗电极大 → 卡T3进度
铬稀有矿产 · 特定区域 → 金属阀组
钛固态电解副产 → 飞船材料
长石月表普遍 → 钠离子电池原料

3.4 气体封装（必经节点）

关键机制：所有制氧路线产出的都是气态 O₂/H₂/CH₄，直接释放到基地。
没有气体压缩机 → 无气瓶 → 无法 EVA 外出 → 无法携带燃料。
舱室 O₂ 不足时自动消耗一个高压氧气瓶补充。

4.2 储气瓶（4级）

储气瓶决定可携带气体总量和外出活动半径。

名称材料重量储气获取瓶颈
T1钢气罐钢（月壤炼铁）大中买 造—
T2钢胆碳纤瓶钢 + 碳纤维中中买 造碳纤维技术
T3铝胆碳纤瓶铝 + 碳纤维轻高买 造铝冶炼耗电大
T4全碳瓶纯碳最轻最高仅自制碳稀有

五、能源系统

5.1 昼夜循环

☀️ 白天（~120s）

太阳能板工作 → ①基地日常 ②盈余充电池 ③再盈余→加热月壤→制水→电解→压缩→气瓶

电力充裕 · 保温耗电低

🌙 夜晚（~120s）

太阳能停工 · 保温耗电↑ → 蓄电池放电 + 燃烧 H₂+O₂ 气瓶发电

电力紧张 · 保温耗电高

时间：1 月球昼夜 = 游戏 240s（现实 4min）· 14 游戏天 ≈ 现实 1 天

5.2 发电模块

☀️ 太阳能模块

产出白天发电 · 夜晚 = 0
升级增加光伏板数量 → 峰值功率↑
盈余→ 蓄电池 → 再余→制气瓶

🔥 燃烧发电模块

原理燃烧 H₂ 瓶 + O₂ 瓶 → 电
本质白天冗余 → 气瓶储存 → 夜晚释放
依赖压缩机 + 储气瓶 + 燃料电池

5.3 电池系统（5级）

电池决定夜间续航能力。储电量 ≠ 放电效率 —— 储得多放得慢也会卡脖子。

名称原料储电放电获取瓶颈 / 特点
T1Ni-MH 镍氢 镍+氢 造 少 低 买 造 皮实但放电慢卡脖子
T2Al-ion 铝离子 铝+钛 造 中 中 买 造 铝冶炼耗电大
T3Na-ion 钠离子 长石 造 中 中上 买 造 原料易得 · 月球长石丰富
T4PFC 燃料电池 H₂+O₂ 造 中 高 买 造 需气瓶产业链成熟
T5RFC 再生燃料电池 H₂+O₂ 造 高 高 末期 再生部件仅末期可造
电池升级卡点设计：
Ni-MH→Al-ion：卡铝冶炼能耗 · Al-ion→Na-ion：卡长石提纯 · Na-ion→PFC：卡气瓶产业链 · PFC→RFC：卡再生部件（终局）

六、通讯系统 · 信号基站（4级）

信号 = 联系地球的命脉。无信号 = 无法网购 = 无法远程采矿 = 放置玩法失效。

名称覆盖网购订单速度价格耗电特殊功能原料
T0 飞行仓应急天线—❌——极低仅自给自足自带
T1 折叠天线阵~100km✅基础慢（2~3昼夜）×1.5低 ~50W—铝+铜 造
T2 相控阵基站~500km✅中级中（1~2昼夜）×1.2中 ~200W📡 资源扫描硅晶片+稀土
T3 深空通讯阵列全月面+轨道✅高级快（0.5~1昼夜）×1.0高 ~1kW🤖 远程采矿 · 📊 储量探测碳纤维结构
T4 量子中继站全太阳系✅终极即时×0.8极高 ~5kW🛸 叫飞船 · 🌍 市场行情量子晶体
信号站游戏节奏：
T0→T1：第一个重大解锁——网购开通，获得兜底保障
T1→T2：解锁资源扫描，不再盲目找矿
T2→T3：解锁远程采矿 = 放置玩法核心（离线后矿机继续工作）
T3→T4：终局钥匙——叫飞船离开月球
⚠️ 信号站必须持续供电，断电 = 信号中断 = 网购和远程控制失效
